# BarQuizz

Тренажер по меню бару: техкарти коктейлів, лимонадів, чаїв, преміксів (бат) і заготовок.

- **Меню** — усі техкарти з пошуком; у кожній позиції схема пропорцій у посуді, спосіб, гарніш, що йде з бату і що додається на сервісі, посилання на заготовки.
- **Картки** — флешкарти з інтервальним повторенням (прогрес зберігається в браузері).
- **Тест** — питання про посуд, спосіб, гарніш, граммовки, бат, вихід і технологію заготовок.
- **Збірка** — зібрати напій по пам'яті: обрати інгредієнти, вписати кількість, посуд і спосіб.

Один файл `index.html`, без збірки — достатньо відкрити його в браузері або викласти на GitHub Pages.
Дані техкарт — у блоці `RAW` на початку скрипта.
